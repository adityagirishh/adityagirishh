## Selected Work (concise)
### RADAR & OriginScale — Adaptive clustering for high-dim data
- Designed deterministic clustering that adapts to local density and scales to thousands of dimensions.  
- Ship-ready library with fast C/Python bindings; consistent improvements vs. competitor algorithms across multiple benchmarks.

### QRAG — Retrieval-Augmented Generation with compressed embeddings
- Introduced binary quantization for embedding storage and a lightweight quality-judge module (QIM) to re-rank retrievals.  
- Focused on reducing memory footprint while preserving recall and end-to-end answer quality.

### FinFusion — Multimodal financial forecasting
- Combined temporal LSTMs with news-sentiment pipelines to improve robustness to regime shifts and news shocks.  
- Designed evaluation metrics emphasizing tail-risk and prediction-stability.
